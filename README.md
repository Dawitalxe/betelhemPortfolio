# Betelhem Melaku — Portfolio Website

A responsive CV + portfolio website built with plain HTML, CSS, and JavaScript.

## Included
- `index.html` — website structure and CV/portfolio content
- `style.css` — responsive layout, colors, typography, and portfolio designs
- `script.js` — mobile navigation, portfolio filters, and project detail popups
- `assets/betelhem-profile.jpg` — edited, web-ready profile image
- `assets/profile-original.png` — original uploaded portrait for future edits


## Customize
- Edit text and project details in `index.html`.
- All four short-form ad cards embed the provided TikTok videos and include their notes in the project details. The poster cards embed the four provided Facebook posts, with descriptions in the project details and the original card dimensions preserved.
- Replace the remaining CSS-generated concept artwork with final client posters, videos, or images when ready.
- Add real case-study links to Feres, eBirr, Kaafi Microfinance, and Desk Digital Marketing when available.
- Contact details are set to `hermitita@gmail.com` and `+251 921 702 551`.
- The CSS-generated portfolio previews are concepts, not verified published client work. Embedded or linked social posts are published by their original accounts.

## Publish
Upload the extracted files to GitHub Pages, Netlify, or another static website host. Keep the `assets` folder alongside `index.html`.
